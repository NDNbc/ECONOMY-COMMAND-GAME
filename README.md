# ECONOMY COMMAND — 5 баг, автомат дараагийн шийдвэр

Багш тоглоомыг нэг удаа эхлүүлнэ. Баг бүр шийдвэр илгээх бүрд сервер автоматаар оноо/үзүүлэлтийг тооцож, тухайн багийн дараагийн цохилтыг нээнэ. Багууд бие даан тоглоно. Бүх баг дуусахад эцсийн тайлан автоматаар гарна.

## Render
Build: `pip install -r requirements.txt`
Start: `gunicorn --bind 0.0.0.0:$PORT app:app`
Environment: `HOST_PIN`, `DATABASE_URL` (байнгын хадгалалтад шаардлагатай).

GitHub-д ZIP доторх файлуудыг (ZIP өөрийг нь биш) оруулж commit хийнэ. `data.json`-ийн түүхэн үйл явдлууд хэвээр.

**Анхаарах:** Өмнөх тоглолтын хадгалсан төлөвт `round` талбар байхгүй бол багийн `log` уртаар сэргээнэ. Өмнөх дуусаагүй тоглолтыг шинэ логикт шилжүүлэхээс өмнө JSON экспорт хийж, шинэ тоглолт эхлүүлэх нь найдвартай.
